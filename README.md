# dmc-terminal

Starter repo for the terminal-onboarding capstone project (see `project.md` in [`ug_onboarding/02_using-the-terminal`](https://github.umn.edu/bartel-group/ug_onboarding/tree/main/02_using-the-terminal)).

Students fork this repo, clone their fork, and work through the capstone questions using `run_experiment.py` and `data/sample_dataset.csv` as the running example.

## Setup
```bash
pip install -r requirements.txt
```

## Running
```bash
python run_experiment.py
```
